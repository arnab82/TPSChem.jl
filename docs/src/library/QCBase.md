# QCBase

Foundational quantum-chemistry data types shared by every method in the
package: atoms, molecules, and molecular-orbital clusters ([`MOCluster`](@ref)),
together with the small generic interface (`n_orb`, `dim_tot`,
`orbital_rotation`, ...) that the other submodules specialize.
