API Overview

TPSChem consolidates the former FermiCG ecosystem into a single package. Each former standalone package lives on as a submodule of the same name:

SubmodulePurpose
QCBaseAtoms, molecules, MO clusters, generic interface
InCoreIntegralsIn-core 1e/2e integrals and transformations
RDMReduced density matrices, orbital gradients/Hessians
BlockDavidsonMatrix-free block-Davidson eigensolver
ActiveSpaceSolversFCI / active-space solver interface
ClusterMeanFieldCluster mean-field (CMF) orbital optimization

The core of the package (the former FermiCG) implements the tensor-product state methods on top of these submodules: TPSCI, SPT, their state representations, and clustered operators.

The module-level docstring:

TPSChem — Module

TPSChem: electronic structure in a tensor product state (TPS) basis.

Consolidates the former FermiCG ecosystem (FermiCG, QCBase, InCoreIntegrals, BlockDavidson, RDM, ActiveSpaceSolvers, ClusterMeanField) into a single package. Each former package lives on as a submodule of the same name.
