Methods & Workflows

TPSChem implements a family of tensor-product-state methods that build on one another. This page is a map: for each method it names the entry-point functions and links to the detailed API. All correlated methods start from a CMF reference and its cluster basis / cluster operators.

The typical pipeline is:

integrals ──► CMF ──► cluster basis + cluster operators ──►  TPSCI ─┐
                                                              SPT ───┼─► +PT2 / +CEPA ─► RDMs / properties

The common preamble

Every correlated method needs three ingredients built once from a CMF solution:

# after a CMF solve gives `ints`, `clusters`, `init_fspace`, and 1-RDM `d1`
cluster_bases = compute_cluster_eigenbasis(ints, clusters; init_fspace=init_fspace,
                                           rdm1a=d1.a, rdm1b=d1.b, max_roots=M)
cluster_ops   = compute_cluster_ops(cluster_bases, ints)
add_cmf_operators!(cluster_ops, cluster_bases, ints, d1.a, d1.b)
clustered_ham = extract_ClusteredTerms(ints, clusters)

cluster_bases are the local many-body states, cluster_ops their operator matrix elements, and clustered_ham the Hamiltonian split into clustered terms.

CMF

Cluster Mean Field — jointly optimize orbitals and local cluster ground states to get the variationally best single tensor product state. This is the reference for everything below.

  • cmf_ci — self-consistent CI at fixed orbitals.
  • cmf_oo — CI + orbital optimization (gradient / CG).
  • cmf_oo_newton, cmf_oo_diis — Newton and DIIS optimizers.

See the CMF example and the ClusterMeanField API.

CMF-PT2 / QDPT

Second-order perturbative correction on top of the CMF (or any small TPSCI) reference, including the quasi-degenerate multi-state variant.

  • compute_pt2_energy — Epstein–Nesbet PT2 on a reference TPSCIstate.
  • compute_qdpt_energy — quasi-degenerate PT2 for several roots.

TPSCI

Tensor Product Selected CI — iteratively grow a sparse set of important tensor-product configurations toward FCI.

  • tpsci_ci — the full selected-CI loop (diagonalize → PT1 → select → grow).
  • tps_ci_direct, tps_ci_davidson — variational diagonalization in a fixed model space.
  • do_fois_ci — expand into and variationally treat the first-order interacting space.

See the TPSCI API.

TPSCI + PT2

  • compute_pt1_wavefunction — first-order (PT1) wavefunction in the FOIS.
  • compute_pt2_energy — PT2 energy correction to a TPSCI reference.

SPT

Subspace Product Tucker — reintroduce discarded tensor products as HOSVD-compressed blocks and solve variationally.

  • subspace_product_tucker — the SPT driver.
  • do_fois_ci — FOIS build/solve for SPTstate.

See the SPT API.

SPT + PT2

  • do_fois_pt2 — build the FOIS and take the PT2 correction.
  • compute_pt2_energy, compute_pt2_energy_blockwise — PT2 energy for an SPTstate.
  • compute_pt1_wavefunction — the SPT PT1 wavefunction.
  • compute_spt_sigma_norm_blockwise — blockwise σ-norm / variance estimate.

TPS-CEPA

Coupled electron-pair-approximation-style corrections that resum higher-order terms beyond PT2 on top of a TPSCI/SPT reference.

  • do_fois_cepa, tpsci_cepa_solve — CEPA over the TPSCI FOIS.
  • tucker_cepa_solve — CEPA in the SPT (Tucker) representation.
  • On the multinode version of these docs, the distributed/sharded solvers (e.g. do_tps_sharded_cepa) run CEPA over a sharded Q-space across nodes — see the Multinode & Sharded page in the API reference.

RDMs

Reduced density matrices from a converged TPSCI wavefunction (see the RDMs & Properties API).

  • compute_1rdm, compute_1rdm_sf — spin-resolved / spin-free 1-RDM.
  • compute_2rdm, compute_2rdm_blas — 2-RDM.
  • *_threaded and *_distributed variants for large problems.

The building-block RDM types (RDM1, RDM2) and orbital gradient/Hessian machinery live in the RDM submodule.

1-RDM properties

One-electron properties, transition properties, and spectra.

  • contract_1rdm_property, compute_1e_property_direct — expectation of a 1e operator.
  • compute_transition_dipoles, compute_oscillator_strengths — transition properties.
  • absorption_spectrum, print_stick_spectrum — spectra.
  • correlation_functions — spin/charge correlation functions.
